# vincentbenlot.site

Vince Benlot's portfolio. `index.html` is the whole site (images are embedded).
Hosted free on GitHub Pages at **https://vincentbenlot.site**.

## Updating
1. Edit `index.html` (featured websites are in the `FEATURED_SITES` list near the bottom).
2. Commit and push to `main`. The site updates in about a minute.

`CNAME` holds the custom domain — don't delete it.
`og-image.jpg` is the preview image for links shared on LinkedIn etc.
