Add it to Gmail

  1. Click Copy full signature above.
  2. In Gmail: ⚙ Settings → See all settings → General, scroll to Signature.
  3. + Create new, name it (e.g. Vince — full), click into the box and paste with ⌘V.
  4. Under Signature defaults, pick it for new emails. Optionally make the compact one for replies/forwards.
  5. Scroll to the bottom and click Save Changes. Send yourself a test email.

Tip: if the copy button is blocked, select the signature box with your mouse, copy, and paste — the formatting comes with it.
